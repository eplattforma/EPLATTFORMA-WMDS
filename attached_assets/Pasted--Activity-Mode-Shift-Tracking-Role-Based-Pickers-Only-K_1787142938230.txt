# Activity Mode + Shift Tracking (Role-Based: Pickers Only)

## Key Change: Role-Based Filtering

**Only staff with `role = 'picker'` get:**
- Shift check-in/check-out times
- Activity modal after packing_complete
- Activity timer mode (Break/Restock/Assist/Repacking)
- Activity session + transition tracking

**All other roles** (Dennis, Eleonora, etc.) skip all of this:
- No shift records
- No activity modal
- No check-in/check-out time
- Tap packing_complete → immediately get next order

---

## Updated Data Model

```sql
-- Shifts table (role-based constraint)
CREATE TABLE shifts (
    id SERIAL PRIMARY KEY,
    assigned_to VARCHAR NOT NULL,  -- picker username
    role VARCHAR NOT NULL,  -- 'picker', 'warehouse_assist', 'supervisor', etc.
    check_in_time TIMESTAMP NOT NULL,
    check_out_time TIMESTAMP,
    total_duration_minutes INT,
    status VARCHAR(50),  -- 'active', 'completed', 'paused'
    CONSTRAINT only_picker_shifts CHECK (role = 'picker')
);

-- Activity tables (only for pickers)
CREATE TABLE picker_activity_session (
    id SERIAL PRIMARY KEY,
    shift_id INT REFERENCES shifts(id),
    picker_username VARCHAR NOT NULL,
    picker_role VARCHAR NOT NULL DEFAULT 'picker',
    
    session_start TIMESTAMP NOT NULL,
    session_end TIMESTAMP,
    previous_order_complete_at TIMESTAMP NOT NULL,
    
    CONSTRAINT must_be_picker CHECK (picker_role = 'picker')
);

CREATE TABLE picker_activity_transition (
    id SERIAL PRIMARY KEY,
    session_id INT REFERENCES picker_activity_session(id),
    
    activity VARCHAR(50) NOT NULL,
    activity_start TIMESTAMP NOT NULL,
    activity_end TIMESTAMP,
    activity_duration_sec INT,
    
    picker_username VARCHAR NOT NULL,
    picker_role VARCHAR NOT NULL DEFAULT 'picker',
    shift_id INT NOT NULL,
    
    CONSTRAINT valid_activity CHECK (activity IN ('break', 'restock', 'assist', 'repacking', 'pick_orders')),
    CONSTRAINT must_be_picker CHECK (picker_role = 'picker')
);
```

## Updated Backend Logic

### 1. Check-In (Only for Pickers)

```python
@app.route('/shift/check-in', methods=['POST'])
def check_in():
    """
    Only pickers check in.
    Other roles skip this entirely.
    """
    data = request.json
    picker_username = data['picker_username']
    picker_role = data['role']  # Required!
    
    # GATE: Only pickers can check in
    if picker_role != 'picker':
        return {
            'status': 'skipped',
            'reason': 'Only pickers have shift check-in',
            'role': picker_role
        }, 200  # Don't error, just skip
    
    # Create shift record
    shift = {
        'assigned_to': picker_username,
        'role': 'picker',
        'check_in_time': datetime.now(),
        'check_out_time': None,
        'status': 'active'
    }
    shift_id = db.shifts.insert_one(shift).inserted_id
    
    return {
        'status': 'checked_in',
        'shift_id': str(shift_id),
        'picker': picker_username
    }
```

### 2. Packing Complete (Activity Modal Only for Pickers)

```python
@app.route('/order/packing-complete', methods=['POST'])
def packing_complete():
    """
    When any role finishes order:
    - If picker → create activity session + show activity modal
    - If other → skip straight to next order
    """
    data = request.json
    invoice_id = data['invoice_id']
    picker_username = data['picker_username']
    picker_role = data['role']  # e.g., 'picker', 'warehouse_assist'
    shift_id = data.get('shift_id')  # pickers will have this
    
    # Update invoice
    invoices.update_one(
        {'_id': invoice_id},
        {
            '$set': {
                'packing_complete_time': datetime.now(),
                'status': 'ready_for_dispatch'
            }
        }
    )
    
    # GATE: Only pickers get activity mode
    if picker_role != 'picker':
        return {
            'status': 'packing_complete',
            'requires_activity_mode': False,
            'role': picker_role,
            'redirect_to': 'next_order'
        }
    
    # Picker: Create activity session
    if not shift_id:
        return {'error': 'Picker must have active shift'}, 400
    
    session = {
        'shift_id': int(shift_id),
        'picker_username': picker_username,
        'picker_role': 'picker',
        'session_start': None,
        'previous_order_complete_at': datetime.now(),
        'session_end': None
    }
    session_id = db.picker_activity_session.insert_one(session).inserted_id
    
    return {
        'status': 'packing_complete',
        'requires_activity_mode': True,
        'session_id': str(session_id),
        'show_activity_modal': True,
        'role': 'picker'
    }
```

### 3. Activity Start (Pickers Only)

```python
@app.route('/activity/start', methods=['POST'])
def start_activity():
    """
    Picker selects activity from modal.
    Non-pickers never reach this endpoint.
    """
    data = request.json
    session_id = ObjectId(data['session_id'])
    activity = data['activity']
    picker_username = data['picker_username']
    picker_role = data['role']
    shift_id = data['shift_id']
    
    # Safety check
    if picker_role != 'picker':
        return {'error': 'Only pickers can use activity mode'}, 403
    
    now = datetime.now()
    
    # Update session
    db.picker_activity_session.update_one(
        {'_id': session_id},
        {'$set': {'session_start': now}}
    )
    
    # Create transition
    transition = {
        'session_id': session_id,
        'activity': activity,
        'activity_start': now,
        'activity_end': None,
        'activity_duration_sec': None,
        'picker_username': picker_username,
        'picker_role': 'picker',
        'shift_id': int(shift_id)
    }
    transition_id = db.picker_activity_transition.insert_one(transition).inserted_id
    
    if activity == 'pick_orders':
        return {
            'status': 'picking_started',
            'redirect_to': 'picking_dashboard'
        }
    else:
        return {
            'status': 'activity_mode_started',
            'activity': activity,
            'show_activity_timer': True
        }
```

### 4. Check-Out (Pickers Only)

```python
@app.route('/shift/check-out', methods=['POST'])
def check_out():
    """
    Only pickers check out.
    """
    data = request.json
    shift_id = data['shift_id']
    picker_role = data['role']
    
    if picker_role != 'picker':
        return {
            'status': 'skipped',
            'reason': 'Only pickers have shift check-out'
        }, 200
    
    db.shifts.update_one(
        {'_id': ObjectId(shift_id)},
        {
            '$set': {
                'check_out_time': datetime.now(),
                'status': 'completed'
            }
        }
    )
    
    return {'status': 'checked_out'}
```

## Updated React Logic

### Check Role Before Showing Modals

```jsx
// PickerApp.jsx
export function PickerApp({ pickerUsername, pickerRole, shiftId }) {
  const isPickerRole = pickerRole === 'picker';
  
  async function onPackingComplete() {
    const response = await fetch('/order/packing-complete', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        invoice_id: currentInvoice.id,
        picker_username: pickerUsername,
        role: pickerRole,
        shift_id: shiftId
      })
    });

    const result = await response.json();

    if (result.requires_activity_mode && isPickerRole) {
      // Show activity modal (ONLY for pickers)
      setActiveSession({
        sessionId: result.session_id,
        pickerRole: pickerRole
      });
    } else {
      // Non-picker: skip straight to next order
      loadNextOrder();
    }
  }

  // Conditional rendering
  if (activeSession && isPickerRole) {
    return <ActivitySelectionModal {...} />;
  }
  
  // Normal picking interface (for all roles)
  return <NormalPickerUI />;
}
```

```sql
-- vw_picker_daily_activity_summary
-- Automatically only shows rows where picker_role = 'picker'

SELECT picker_username, DATE(session_start) as work_date,
  break_total_min, restock_total_min, assist_total_min, repacking_total_min
FROM vw_picker_daily_activity_summary
WHERE picker_role = 'picker';

-- vw_picker_activity_patterns
SELECT picker_username, activity,
  occurrence_count, avg_duration_sec, median_sec

WHERE picker_role = 'picker';
```

```jsx
export function ShiftControls({ pickerRole, pickerUsername, onCheckIn, onCheckOut }) {
```

## Test Scenarios

### Scenario 1: Arslan (Picker)
```
1. App loads, shows "Check In" button
2. Arslan taps "Check In" → shift record created, status=active
3. Arslan picks orders, finishes one
4. Taps "Packing Complete" → Activity Modal appears
5. Selects "Break" → Timer mode, elapsed time visible
6. 5 min later, taps "Pick Orders" → Session ends, goes to picking dashboard
7. End of day: Taps "Check Out" → shift record updated with check_out_time
```

### Scenario 2: Dennis (Not Picker)
```
1. App loads, NO "Check In" button (or grayed out)
2. Dennis logs in, goes straight to picking orders
3. Dennis picks orders, finishes one
4. Taps "Packing Complete" → NO activity modal
   → Immediately gets next order assignment
5. No check-out needed (no shift tracking)
```

### Scenario 3: Multi-Role Case
```
If Arslan's role = 'picker' + 'warehouse_assist' (both roles):
- Check system: is primary_role = 'picker'?
- If yes → full tracking
- If no → skip
(Or: require picker to have ONLY role='picker' if this is strict)
```

## Deployment Changes

1. **Require `role` field** in all auth/session data (pass it through API)
2. **Add role checks** in all packing_complete, activity/*, shift/* endpoints
3. **Conditional UI:** Check role before rendering:
   - Check-in/check-out buttons
   - Activity modal after packing_complete
   - Shift duration display
4. **No changes needed** for picking orders flow (all roles can pick, just different tracking)
