Upload the Magento customer export. The importer looks for three columns: the Magento customer ID (entity_id / id), the customer group (group_id / group) and the PS365 code (customer_code_365 or any column containing “365”). Rows with a blank PS365 code are skipped. Re-uploading is safe — existing mappings are updated, not duplicated. The rest of the system reads the mapping through the vw_customer_magento view.
